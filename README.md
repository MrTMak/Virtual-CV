# 🌐 Thapelo Makile - Virtual CV Portfolio

## 📖 Overview

This project is a personal portfolio website (Virtual CV) developed as part of the Profile Development assignment.

The website serves as an online professional profile, showcasing my education, work experience, technical skills, certifications, and projects. It is designed to provide potential employers and collaborators with an interactive and modern overview of my professional background.

---

## Project Objectives

- Create a professional online CV
- Demonstrate HTML, CSS, and JavaScript skills
- Showcase my projects and achievements
- Provide quick access to my downloadable CV
- Present my professional profile in a modern and responsive design

---

## Features

The portfolio includes the following sections:

-  Home
-  About Me
-  Work Experience
-  Education
-  Projects
-  Technical Skills
-  Certifications
-  Downloadable CV

## ⚙️ Installation

To run this project locally:

### 1. Clone the repository

```bash
git clone https://github.com/yourusername/Virtual-CV.git
```

### 2. Open the project folder

```bash
cd Virtual-CV
```

### 3. Open the project

Open the folder using Visual Studio Code.

### 4. Run the website

Option 1

Open **index.html** directly in your browser.

Option 2 (Recommended)

Use the **Live Server** extension in Visual Studio Code.

Right-click on **index.html**

Select:

```
Open with Live Server
```

The website will open in your default browser.
